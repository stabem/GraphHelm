Immutable history tables reject UPDATE/DELETE even for an accidentally over-granted non-replication session; stream heads accept only monotonic append transitions.

The complete Task 6 append and envelope integrity path now lives once in `core/events`. Both Local and PostgreSQL use the same bounded durable-content/schema, Evidence metadata/bijection/orphan, artifact producer/ownership, graph lineage, request digest, envelope and event-hash primitives. Local journal bytes and exact-retry behavior remain unchanged. `EventPage` carries the authoritative head. PostgreSQL reads bind physical tail to a provider-authenticated stream head refreshed on every append and, when present, bind the entire bounded suffix to a provider-authenticated checkpoint whose canonical bytes include key version and provider epoch. A database-only attacker therefore cannot rehash a checkpoint suffix and replace the database head without a fresh provider tag.
