The Studio bundles these font files. They are third-party font software under the SIL Open Font
License, Version 1.1 (OFL-1.1), rather than the repository's MIT code license.

| File | Font and embedded version | Copyright and license |
| --- | --- | --- |
| `jetbrains-mono-latin.woff2` | JetBrains Mono Regular 2.211 | [JetBrains Mono OFL](OFL-JetBrains-Mono.txt) |
| `space-grotesk-latin.woff2` | Space Grotesk Light 2.000 | [Space Grotesk OFL](OFL-Space-Grotesk.txt) |

The license texts and copyright notices are distributed with the font files. Their upstream
sources are [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) and
[Space Grotesk](https://github.com/floriankarsten/space-grotesk).
