# Source provenance

This public source tree starts with a single reviewed import commit. Earlier private development
history, pull requests, issues, Actions logs, and internal branches are not part of this repository.
The import preserves the current code and its license attribution while replacing machine-specific
paths in examples, tests, and historical acceptance records with sample paths.

Historical acceptance records are retained for context. Their local paths have been substituted,
so they are not byte-for-byte copies of the original runs and must not be used as fresh validation
of this import. Commit identifiers and issue numbers in older documents refer to private
development records and may not resolve in this public repository. The current source and the
published tests are the starting point for new contributions and validation.

The import was scanned before publication. Scanner findings and their private triage are kept
outside this repository so that potential secret values and internal machine details are not
republished. A scan is evidence for the revision it examined, not a guarantee about future code.
