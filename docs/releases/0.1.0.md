# GraphHelm CLI 0.1.0 preview

This is the first public **preview** of the GraphHelm command-line application. It is experimental, with no stable compatibility promise. The CLI can validate graphs, run local fixture executions, expose the Runtime API and MCP surface, and preview host setup. The [roadmap](../product/ROADMAP_AND_ACCEPTANCE.md) distinguishes working features from planned ones.

## Downloads

The [GitHub release](https://github.com/stabem/GraphHelm/releases/tag/v0.1.0) contains:

| Archive | Host used for build and smoke test | Contents |
| --- | --- | --- |
| `graphhelm-v0.1.0-windows-x86_64.zip` | Windows x86-64 | `graphhelm.exe`, bundled setup extensions, MIT license, package README |
| `graphhelm-v0.1.0-linux-x86_64.tar.gz` | Ubuntu 24.04 x86-64 | `graphhelm`, bundled setup extensions, MIT license, package README |
| `SHA256SUMS.txt` | Both | SHA-256 digest of each archive |

Download an archive and `SHA256SUMS.txt` from the same release. Compare the archive's SHA-256 digest with its line in `SHA256SUMS.txt` **before extraction**. On Windows run `Get-FileHash -Algorithm SHA256 .\graphhelm-v0.1.0-windows-x86_64.zip`; on Linux run `sha256sum graphhelm-v0.1.0-linux-x86_64.tar.gz`. Extract the archive and run `graphhelm --version`. To check behavior without a model account or service, use the [offline quickstart](../../QUICKSTART.md). Its graph example and Studio files come from the repository, not the CLI archive.

The archives contain the CLI only. The Studio, example files, VPS installer, and extension source are in the [tagged repository](https://github.com/stabem/GraphHelm/tree/v0.1.0). For macOS, ARM, and other hosts, [build from source](../install/GETTING_STARTED.md). A Linux archive built on Ubuntu 24.04 requires a compatible glibc system; other distributions are not claimed as tested.

## Release checks

This release is built locally from the tagged `main` commit. Each binary must be exercised from an extracted archive outside the source tree with `--version`, `--help`, an offline graph validation command, and a setup preview that loads the bundled extension manifest. Archive hashes must match `SHA256SUMS.txt`. GitHub Actions are intentionally disabled; no hosted CI result is implied by the release.

Report defects with a [GitHub issue](https://github.com/stabem/GraphHelm/issues/new/choose). Send security reports through the [private channel](../../SECURITY.md).
