# GraphHelm CLI 0.1.1 preview

This experimental preview includes the public audit corrections in issues #141 through #154. It has no stable compatibility promise. The CLI and local Runtime are packaged; the Studio remains in the tagged source and runs from source.

## What changed

- Studio source: graph verification stays bound to the current path; stalled Runtime reads and stale reconnect state no longer keep the screen in a false LIVE state; credential-save recovery asks before discarding partial work; the vulnerable `undici` lock entry was refreshed.
- CLI and Runtime: WebMCP can retry an uncertain `start_task` with its original identity; the Keel prover bounds post-exit pipe draining and preserves process exit status; incomplete inline grafts remain unproven, and parameterized TypeScript tests are reported.
- Setup: the release bundles the current project-aware host adoption flow. The development-contracts extension is version 0.1.1 with a validated content digest; the unchanged JPD extension remains 0.1.0.

The [release](https://github.com/stabem/GraphHelm/releases/tag/v0.1.1) provides Windows x86-64 and Ubuntu 24.04 x86-64 CLI archives and `SHA256SUMS.txt`. Verify the archive hash before extraction. Run the extracted `graphhelm --version`, `graphhelm --help`, an offline graph validation command, and `graphhelm setup` preview before adopting it in a project. The [installation guide](../install/GETTING_STARTED.md) covers the full Runtime and Studio journey.

The binaries are built locally from the tagged `main` commit with Rust 1.97.1 and `--locked --release`. Each archive is tested outside the source tree and includes both validated extension packages, `LICENSE`, and a package README. GitHub Actions remain disabled; no hosted CI or deployment is implied. macOS, ARM, and other Linux distributions are not claimed as tested; [build from source](../install/GETTING_STARTED.md) there.
