# GraphHelm 1.0.0

1.0.0 is the first version with a compatibility promise. It marks the four MVP promises of
[ROADMAP §3.2.1](../product/ROADMAP_AND_ACCEPTANCE.md) held on `main`; the major bump follows
[RELEASE.md](../process/RELEASE.md). Every Cargo crate and every plugin and builtin extension
manifest is 1.0.0.

- Archives: Windows x86-64 and Ubuntu 24.04 x86-64 CLI archives with `SHA256SUMS.txt`, the same
  targets as 0.1.1, built locally with Rust 1.97.1 and `--locked --release` and tested from outside
  the source tree. GitHub Actions remain disabled; no hosted CI or deployment is implied.
- **The Studio does not ship as a binary.** It ships in the tag's source and runs from source; see
  [getting started](../install/GETTING_STARTED.md).
- Range: the 0.1.1 preview to the release commit.

Terms used below: **Studio** is the GraphHelm web app. **Runtime** is the local service behind the CLI and the Studio. **Keel** is the construction pattern (cards, hooks and skills that gate code work). **JPD** is Journey-Proven Development: work is done when an observer proves the user-visible promise.

## The four promises

Release 1.0.0 needs all four to hold on `main`, each with a receipt linked from the release PR.

| # | Promise | Receipt |
|---|---|---|

| 4 | Provider-less mode | held by `apps/cli/tests/providerless_journey.rs`; Tsunade's rerun on `main` (TODO link on #2301) |

## Known limits

Each limit below has a source PR.

- The self-review stop is opt-in, and it runs only when a project turns it on (#2267).
- Under extreme disk load (cargo -j32), between 6% and 27% of session ends took longer than Claude Code's ~10 s in OS teardown after the hook answered, so that session's end signal can be lost. Session start exceeded its 30 s budget in 0 of 24, 0 of 85 and 1 of 90 runs across the probes (#2340).
- On Codex (cli 0.157.1), the host clamps SessionEnd to 3 s regardless of the declared timeout (observed 2026-10-31); the end signal may be lost under load (#2340).
- In Claude Code, SessionEnd was cancelled ~10 s even when declared 30; SessionStart honours 30 s (observed 2026-10-31, print mode) (#2340).
- GraphHelm's hook running inside Codex: OBSERVER_MISSING (#2340).
- In a large repository the first source search builds the index and can take over a minute; later searches read the index (#2319).
- A real-executor start sent with `Prefer: respond-async` (the MCP `start` tool sends it) answers 202 once the run is committed; a later drive or workspace-release failure is then reported only on the Runtime's stderr, status may keep showing the run as running, and a failed release keeps the execution's workspace (no expiry) until the execution is driven again or the operator runs `graphhelm workspace remove <staging>/ghtool-exec-<id digest>` (#2352, #2357).
- The install check runs only a CLI built from head (#2273).
- Setup installs the browser journey observer with Playwright by default, and the e2e runner is opt-in (#257).
- An autopilot pauses until restart when its launcher is not found or a configured exit code is returned (#2007).
- Journey CLI acts run only an allowlisted script runner (#2216).
- A Keel effect record without an effect set reports `unknown` (#2209).
- Benchmark limits are listed in the Benchmark section (#2074).
