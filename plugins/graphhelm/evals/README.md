Each `-unprompted` eval is a twin of the corresponding prompted eval: it keeps the same scenario, frontmatter, and grading criteria, removes the sentence naming the skill, and adds one pass condition requiring the transcript to show the expected skill invocation. These twins measure whether an agent selects the skill without being told its name, as well as its behavior after selection. Run `python -m pytest tools/evals/test_skill_twins.py` to check pairing offline; this lint does not run models or establish skill selection rates.

Selection coverage (#184): `guide-newcomer` and `kickoff-from-zero` each have an `-unprompted` twin, and `no-skill-setup-grammar` and `no-skill-customer-journey` are negative cases that must end with no Skill invocation (a failed run is INCOMPLETE, never a pass). `graphhelm-team` has no case yet. The deterministic selection grader is qualified offline on recorded transcripts with `python tools/evals/grader_qualification.py`. No model result is claimed.
