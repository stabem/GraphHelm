**Keel's table treats every config change as trivial**

The Keel table in the delivery docs (and the copy in AGENTS.md) lists "config values" next to docs
and comments, so they need nothing beyond a summary. But a one-line Runtime timeout or permission
change alters behaviour. Expected: only inert config (a display label, say) stays on the light row;
runtime- or security-affecting config goes to the expanded route and needs behavioural evidence.
